Vidéos pratiques

Mobilisation du bassin

Position :

• Allongée sur le dos

• Genoux pliés + un peu écartés, pieds à plat

Consignes :

• Mettre un coussin ou un vêtement plié sous les fesses

• Faire tourner le bassin : 10x dans chaque sens

Étirement Papillon

Position :

• Allongée sur le dos

• Genoux écartés

• Mains à l’intérieur des genoux

Consignes :

• Ramener les genoux contre le ventre

• Faire tomber les genoux sur les côtés

• Sentir l’étirement à l'intérieur des jambes : tenir 30 secondes

Contracté/relâché du périnée sur le dos

Position :

• Allongée sur le dos

• Genoux pliés + un peu écartés, pieds à plat

• Mains sur le ventre pour sentir la respiration

Consignes :

• 2x10 ou 2x5 répétitions en fonction de vos capacités (30 sec de pause entre les séries)

• Inspirer par le nez : le ventre se gonfle, relâcher le périnée

• Souffler par la bouche : contracter le périnée haut et loin, le ventre rentre un peu

• Maintenir quelques secondes

• Inspirer : relâcher le périnée, le ventre se gonfle

Idées d’images à utiliser :

• Se retenir de faire pipi/ retenir un gaz

• Cueillir un noyau de cerise avec une petite pince entre l’anus et le vagin, l’emmener haut et loin lors de la contraction et le redéposer lorsqu’on relâche

• L’ascenceur/ le périnée qui monte jusqu’au toit/ la tête puis redescend jusqu’au rez-de-chaussée

Happy Baby

Position :

• Allongée sur le dos

• Genoux à 90° écartés et ramenés contre le ventre

• Mains qui attrapent les pieds par l'intérieur

• Adaptation 1 : attraper à l'intérieur des chevilles ou des mollets

• Adaptation 2 : attraper derrière les cuisses par l’extérieur !! Garder les genoux écartés

Consignes :

• Ramener les genoux contre le ventre

• Ecarter les genoux + les plier à 90°

• S'attraper les pieds avec les mains par l'intérieur (les coudes sont à l'intérieur des genoux)

• Tenir 30 secondes

• Si attraper les pieds est trop difficile ou cause une douleur, utiliser l’adaptation 1

• Si cela est toujours trop difficile ou cause une douleur, utiliser l’adaptation 2
